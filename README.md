# Geographical Business Intelligence and Sales Analysis

## Tableau Dashboard
View Interactive Dashboard-(https://public.tableau.com/app/profile/sandhya.dharmaraj/viz/GeographicalBusinessIntelligenceandSalesAnalysis/GeographicalSalesandProfitAnalysis)

## Project Overview
This project uses Tableau Public to perform geographical analysis of the Sample Superstore dataset. It explores sales and profit variations across states, cities, regions, and product categories through interactive maps and visualizations.

## Objective
To identify geographical business patterns, compare regional performance, analyze location-based sales and profitability, and provide data-driven recommendations.

## Tools Used
- Tableau Public
- Sample Superstore Dataset
- GitHub

## Geographical Fields
- Country
- State
- City
- Region

## Visualizations
1. State-wise Profit Map
2. City-wise Sales Map
3. Regional Sales Analysis
4. Top 10 States by Profit
5. Region Category Treemap

## Interactive Features
- Year of Order Date Filter
- Region Filter
- Category Filter
- Interactive geographical maps

## Key Findings
- Identify states with the highest and lowest profitability.
- Compare sales performance across different cities and regions.
- Identify product categories contributing to regional sales performance.

## Suggestions and Recommendations
- Improve marketing strategies in low-performing geographical areas.
- Focus on profitable states and cities.
- Review pricing and discount strategies to improve regional profitability.

## Conclusion
The geographical analysis helps identify variations in sales and profit across different locations. The interactive Tableau dashboard supports better geographical comparisons and data-driven business decisions.
